# Tarkov Helper

Aplicativo para Windows x64 para acompanhar missões de Escape from Tarkov e planejar raids, com progresso local separado para PvE e PvP.

[Baixar o instalador mais recente](https://github.com/boludoplay/TarkovHelper-Releases/releases/latest/download/BoludoPlay.TarkovHelper-win-Setup.exe)

## Para começar

1. Baixe e execute o instalador.
2. Abra **Tarkov Helper** pelo atalho na área de trabalho ou no menu Iniciar.
3. Se necessário, escolha a pasta do jogo ou a subpasta **Logs** em **Configurações → Escolher pasta**.

O .NET está incluído; não precisa de Visual Studio. A primeira abertura precisa de internet para carregar as missões e imagens. O progresso depende dos logs gerados pelo seu próprio jogo.

## Atualizações

O app verifica novidades ao abrir, baixa em segundo plano e aplica na próxima abertura. Também há **Verificar atualizações** e **Reiniciar para atualizar** nas configurações. As marcações e preferências são preservadas.

Este repositório contém somente arquivos de distribuição. Não contém código-fonte, logs, perfis ou dados de jogadores.

Versão beta, sem assinatura digital: o Windows pode mostrar um aviso de editor desconhecido. Não altere a segurança do computador; se uma política bloquear a execução, será necessário disponibilizar uma versão assinada.

Projeto independente, não afiliado à Battlestate Games. Escape from Tarkov e seus conteúdos pertencem aos respectivos titulares.
